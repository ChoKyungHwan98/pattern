# ADR 0002: Tauri 데스크톱과 로컬 자산

상태: 승인

## 결정

- 주 실행 환경은 Tauri 2 데스크톱 앱이다.
- 사용자가 선택한 프로젝트와 문서·다운로드·데스크톱·앱 데이터 범위만 파일 권한을 허용한다.
- 캐릭터, 모션, 효과, 소리는 개인 로컬 라이브러리에 둔다.
- 프로젝트 문서에는 자산 ID, 경로, 체크섬, 라이선스 메모만 저장한다.
- 실제 자산이 없으면 원시 도형을 캐릭터 대신 표시하지 않는다.

## 이유

대용량 에셋과 라이선스를 안전하게 로컬에 유지하고 Unity·Unreal 내보내기 파일을 생성할
수 있어야 하기 때문이다.
